# Casino Lab MVP

Учебное мини-казино: Node.js + Express, SQLite, простые HTML/JS страницы. Сессии через `express-session`. Один контейнер (backend + статик).

## Запуск
1. Собрать и поднять: `docker compose up --build`
2. Открыть: http://localhost:3000 (главная с регистрацией/логином)

или 
```
docker compose build --no-cache
docker compose up
```

## Регистрация и промокод
- При регистрации укажите логин/пароль.
- Промокод `SCAM` выдает 1000₽ фрибетов (основной баланс остается 0).

## Страницы
- `/index.html` — регистрация и логин.
- `/profile.html` — профиль, основной баланс и фрибеты.
- `/slots.html` — список слотов, далее отдельные страницы `/slot-a.html`, `/slot-b.html`.
- `/bets.html` — шаблон страницы ставок (UI без логики, см. комментарий `// Betting logic will be implemented later`).

## Слоты и точка расширения под уязвимость
- Код слотов: `server.js`, функция `calculateOutcome` — содержит TODO-комментарий о будущей клиентской примеси случайности (инsecure design placeholder). Сейчас логика безопасная, использует серверный `Math.random`.
- У каждого слота фиксированные ставка/выигрыш, можно платить обычным балансом или фрибетами.

## Откат состояния (reset)
```
chmod +x reset.sh
```
SQLite хранится в Docker volume `db_data`. Для сброса:
```bash
./reset.sh
```
Скрипт остановит контейнер, удалит volume с базой и поднимет свежий инстанс.

## Заметки
- Сессии хранятся в памяти контейнера.
- Пароли хэшируются через `bcryptjs` с простыми настройками (подходит для учебного стенда).
